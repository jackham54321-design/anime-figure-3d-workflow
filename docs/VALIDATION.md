# 验证结果与范围

## 原生A2

源A2与最终摄影场景的保护资产语义一致；发布副本只清理私有绝对路径、无关元数据和可读名称。复开验证几何、UV、角点法线、材质值/链接及7张打包图像编码字节均保持。没有外链Blend库，7张图像全部可解码。源A2、V4、供体与原视频未改。

## GLB

从真正A2导出选中的人物/底座，不应用修改器、不重拓扑、无减面、无图片重采样。GLB含1网格、3个有效材质分区、1,963,301三角面；原生未使用的第4材质槽无需导出。重新导入干净Blender场景后，按材质与实际三角角点对应比较：世界坐标最大误差0，UV最大误差0；123面下巴隔离仍在。顶点由1,027,835拆为1,087,450，不是形体变化。

7张嵌入图像与源打包字节逐一SHA256相同，3张底色8192²，其余4张法线/金属粗糙度4096²。基础PBR材质、法线链接与采样设置核对通过。

**法线不逐位一致。** 直接读取GLB法线最大角差0.00481°，Blender重导入后最大角点差0.10271°（全主体RMS约0.00241°）。原严格检查失败记录保留，没有改阈值把它变成精确等价。GLB定位为有限制的查看/交换副本，精确编辑使用.blend。

## 真实渲染对照

源场景、脱敏原生和GLB重导入分别渲染相同全身/面部视角，均为1080方、64采样、相同光照/曝光，无景深或运动模糊。实际查看三列全身、脸部和剑刃100%裁切，未见新增明显形变、串色、接缝或细节损失。

脱敏原生面部像素完全相同；全身仅1像素有1级8bit差异。GLB与源全身最大通道差4，面部最大21；面部1,166,400像素中14像素差值超过8，平均通道绝对误差0.000718（0–255尺度）。这些结果不覆盖所有角度和第三方引擎，也不消除模型原有残留瑕疵。
