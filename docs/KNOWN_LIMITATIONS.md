# 当前A2限制

| 区域/用途 | 当前结论 |
|---|---|
| 下巴微点 | A1法线＋A2底色最小修复已接受；不代表整张脸无瑕疵 |
| 眉上白凸脊 | 实体凸脊及折返多层；B1拒收，需人工确定两端接口和保守目标曲面 |
| 遮眼刘海 | 真实遮挡；调整依赖眉脊与眼睑间隙判断，未实施最终几何修复 |
| 人物左耳前细条/外卷根部 | 与头部融合的完整接口不确定；没有精准去除成功的声明 |
| 发饰接触处 | 材质边界与真实折缝共同作用，剩余原因UNKNOWN |
| 衣领黑破边 | 未解决，不能全部解释为正常阴影，也不能刷成皮肤色 |
| 背面与不可见区域 | 由单图推断，不能声称与未知设计真值一致 |
| 打印 | 未验证封闭性、壁厚、支撑、切片或实际打印 |
| 动画/游戏 | 未绑定、未做变形测试、LOD、碰撞或性能预算 |
| A2 GLB | 当前不存在经过验证的最终A2 GLB；两份原始供体不包含局部修复 |
| 可复现性 | 云端生成具有版本/服务依赖，即使种子相同也不承诺字节相同；公开资产尚未提供 |

最终A2保留原模型的姿态、形体和UV。几何试验不因技术指标暂时通过就取得艺术验收；没有将全局重网格、减面或磨平脸用作遮瑕。仓库中的流程也不是专业打印/法律认证。
